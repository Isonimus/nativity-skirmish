# Nativity Skirmish: concept note

## Summary

Nativity: Skirmish treats a Christmas nativity display as a miniature skirmish ecosystem. The joke is that the game uses the same figures people already own, but the structure is deliberately serious: factions, objectives, terrain, morale, and campaign progression.

## The core idea

The core loop should feel like a small, absurdly earnest wargame:

- each model belongs to a faction or a neutral role
- the battlefield is built from the nativity set itself
- scenarios are drawn from nativity traditions rather than conventional war games
- the Holy Family is both a narrative anchor and an objective worth defending

## Why it has value

This concept has value because it is simultaneously:

- low-friction to prototype, since the miniatures already exist
- funny without being shallow, because the rules can be genuinely playable
- good for seasonal events, family play, and community games
- strong as a "serious joke" system where the absurdity enhances the rules rather than replacing them

## Design direction

1. Keep the tone dead-serious.
   The manual should sound like a proper skirmish rulebook, even when the models are sheep, kings, and a fisherman with no clear purpose.
2. Make the nativity set itself the battlefield.
   Stable, road, market, river, well, and shepherd's pen should be terrain features that the set already provides.
3. Use asymmetric factions.
   The Holy Family, shepherds, Magi, Romans, and Herod each need a different play style.
4. Make civilians matter.
   Neutral figures create emergent story and can become objectives, liabilities, or tools.
5. Build around scenarios.
   The game should not be "kill everything"; it should be about census, shelter, escort, star-following, night movement, or protection.

## Suggested first version

A strong first release would be a small ruleset with:

- 2-4 players
- 20-40 models per side
- a fixed set of objectives
- a simple activation system
- a lightweight campaign roster

The first scenario should be "The Journey": the Holy Family must move across the board while other factions contest the route, protect civilians, or intercept them.

## Verification

- Review the concept against the criteria of playability, humor, and low barrier to entry.
- Check that the structure is clear enough to turn into a first prototype.
- Confirm that the core pillars are distinct from a simple parody.
